# SocialHub v11.0 - Guía Profesional Softgam.com

## 🚀 Descripción

Softgam SocialHub es la evolución definitiva en CRM y gestión de redes sociales para el mercado colombiano. Esta versión 11.0 integra capacidades de comunicación omnicanal en tiempo real, automatización por IA y una estructura PWA optimizada para movilidad total.

## ✨ Módulos de Potencia

- **Omni-Channel Inbox**: Centralización total de WhatsApp Business, Twilio Voice y Redes Sociales.
- **CRM Dinámico**: Gestión de leads con pipeline visual "Neon Forest Green".
- **AI Suite v4.0**: Generación masiva de contenido y estrategias de marketing automatizadas.
- **Project Engine**: Control de proyectos y tareas con metodología ágil.
- **Invoicing Pro**: Facturación y métricas de ventas en tiempo real.

## 🛠️ Stack Tecnológico

- **Core**: React 18, Node.js 20, TypeScript.
- **Data**: PostgreSQL + Drizzle ORM (WAL Mode).
- **Style**: Neon Forest Green Design System (Tailwind + Shadcn).
- **PWA**: Service Workers integrados para modo offline.

## 📦 Despliegue Rápido

1. `npm install`
2. `npm run db:push`
3. `npm run dev`
