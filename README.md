# SocialHub - Plataforma Unificada de Gestión de Redes Sociales

SocialHub es una solución integral diseñada para centralizar la gestión de interacciones en múltiples plataformas (WhatsApp, Instagram, Facebook) y potenciar el crecimiento mediante automatización inteligente, analítica avanzada y herramientas de marketing.

## 🚀 Características Principales

- **Gestión Multiplataforma**: Centraliza mensajes de WhatsApp, Instagram y Facebook en una sola bandeja de entrada inteligente.
- **Orquestador de IA**: Automatización de respuestas mediante agentes de IA que pueden manejar consultas comunes y realizar traspasos a agentes humanos cuando sea necesario.
- **Generador de Contenido Inteligente**: Crea publicaciones, scripts y contenido promocional utilizando modelos de lenguaje avanzados adaptados a tu negocio.
- **Dashboard de Analítica**: Visualiza el rendimiento de tus campañas, tasas de interacción y crecimiento de seguidores en tiempo real.
- **Constructor de Funnels**: Diseña y automatiza embudos de ventas personalizados para convertir prospectos en clientes.
- **Gestión de Catálogo e Inventario**: Sincroniza tus productos y gestiona el stock directamente desde la plataforma.
- **Acortador de Enlaces Personalizado**: Crea y rastrea enlaces para tus campañas de marketing con analítica detallada de clics.

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React, Vite, TailwindCSS, Shadcn UI, Framer Motion, Recharts.
- **Backend**: Node.js, Express, TypeScript.
- **Base de Datos**: PostgreSQL con Drizzle ORM.
- **IA**: Integración con OpenAI para procesamiento de lenguaje natural.
- **APIs**: WhatsApp Web.js, Instagram Private API, Google APIs, Spotify Web API.

## 📦 Instalación y Desarrollo

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Configurar variables de entorno**:
   Crea un archivo `.env` o utiliza los secretos de Replit para las claves de API (OpenAI, Meta, etc.).

3. **Ejecutar en modo desarrollo**:
   ```bash
   npm run dev
   ```

## 📱 Integraciones de WhatsApp

La plataforma incluye soporte avanzado para:
- **WhatsApp Cloud API**: Integración oficial mediante webhooks.
- **WhatsApp Web.js / Baileys**: Conexión mediante escaneo de código QR para automatización de cuentas personales y de empresa.
