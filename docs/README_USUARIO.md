# SoftganHub - Guía del Usuario

## Bienvenido a SoftganHub v11.0

SoftganHub es tu plataforma centralizada para gestionar comunicaciones con clientes, ventas y operaciones comerciales. Esta guía te ayudará a sacar el máximo provecho del sistema.

---

## Acceso al Sistema

### Iniciar Sesión

1. Abre tu navegador y accede a la URL de SoftganHub
2. Ingresa tu usuario y contraseña proporcionados por el administrador
3. Haz clic en "Iniciar Sesión"

### Cerrar Sesión

- Haz clic en el botón de salida (icono de puerta) en la esquina superior derecha

---

## Panel de Control (Dashboard)

El Dashboard es tu centro de operaciones. Aquí encontrarás:

### Métricas Principales

- **Clientes Activos**: Total de clientes en tu base de datos
- **Órdenes de Compra**: Pedidos pendientes y completados
- **Funnels Activos**: Embudos de ventas en funcionamiento
- **Bot Respuestas**: Mensajes automatizados enviados
- **Ventas del Mes**: Ingresos generados
- **Tasa de Conversión**: Porcentaje de leads convertidos

### Widgets Disponibles

- Actividad semanal (gráfico)
- Bot de Ventas IA (rendimiento)
- Órdenes de Compra recientes
- Pipeline de ventas
- Estado del sistema

## Módulos Principales

### 1. Inbox (Bandeja de Entrada)

Centro unificado de mensajes de WhatsApp, Instagram y Facebook.

**Cómo usar:**

- Los mensajes nuevos aparecen automáticamente
- Haz clic en una conversación para responder
- Usa las respuestas sugeridas por IA para agilizar
- Marca conversaciones como resueltas cuando termines

### 2. Clientes

Gestión completa de tu base de clientes.

**Funciones:**

- Agregar nuevos clientes
- Editar información de contacto
- Ver historial de interacciones
- Clasificar por estado (nuevo, activo, inactivo)

### 3. Órdenes de Compra

Sistema de gestión de pedidos.

**Estados de órdenes:**

- 🟡 **Pendiente**: Orden recibida, esperando aprobación
- 🔵 **En Proceso**: Orden aprobada, en preparación
- 🟢 **Completada**: Orden entregada
- 🔴 **Cancelada**: Orden anulada

**Crear una orden:**

1. Ve a "Órdenes" desde el menú
2. Haz clic en "+ Nueva Orden"
3. Selecciona el cliente
4. Agrega productos y cantidades
5. Confirma la orden

### 4. Funnels de Ventas

Embudos de conversión para seguimiento de prospectos.

**Tipos de funnels:**

- Ventas directas
- Captación de leads
- Webinars
- Lanzamiento de productos

**Gestión:**

- Crea nuevos funnels
- Personaliza las etapas
- Duplica funnels exitosos
- Pausa o activa según necesidad

### 5. Bot de Ventas IA

Agente automatizado que responde consultas 24/7.

**Beneficios:**

- Respuestas instantáneas
- Cualificación automática de leads
- Integración con WhatsApp
- Transferencia a agente humano cuando es necesario

### 6. Campañas

Marketing masivo a través de todos los canales.

**Crear campaña:**

1. Define el objetivo
2. Selecciona la audiencia
3. Diseña el mensaje (o usa IA)
4. Programa el envío
5. Monitorea resultados

## Consejos y Mejores Prácticas

### Para Vendedores

1. Revisa el Dashboard cada mañana
2. Responde mensajes en menos de 5 minutos
3. Usa las plantillas para respuestas frecuentes
4. Actualiza el estado de las órdenes regularmente
5. Documenta notas importantes en cada cliente

### Para Atención al Cliente

1. Prioriza tickets urgentes
2. Usa el historial del cliente antes de responder
3. Escala casos complejos al supervisor
4. Cierra tickets resueltos para mantener orden

## Preguntas Frecuentes

**¿Por qué no veo mis mensajes de WhatsApp?**

- Verifica que la cuenta esté conectada en "Plataformas"
- Revisa tu conexión a internet

**¿Cómo cambio mi contraseña?**

- Ve a Configuración > Cuenta > Cambiar Contraseña

**¿Puedo usar SoftganHub desde el celular?**

- Sí, es una PWA. Puedes instalarlo como app desde el navegador.
